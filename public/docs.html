bothub · API v1

Dashboard

The bothub pairing API lets you drive WhatsApp pairing from anywhere — your own bot, a website, a script — without running Baileys yourself. Send a phone number and a level to POST /api/v1/sessions with your bh-… key, and the API returns a pairing code valid for about 60 seconds. The behavior you selected runs the moment the account finishes logging in, and the session is tracked from your dashboard until WhatsApp ends it.

Get a key. Sign in at /dashboard, create an account, then generate a key. Keys start with bh-.

Base URL

https://bothub-1vmg.onrender.com

Authentication

Every request to /api/v1/* must carry your key in the Authorization header:

Authorization: Bearer bh-XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX

Levels

The level field selects what happens once the account logs in.

LevelBehavior
1Text flood — one-character bodies to random non-contact JIDs
2Heavier text flood — same, faster
3Flood + sticker spam (uses assets/sticker.png if present)
4Flood + stickers + oversized bodies (60,000 characters per send)
5Request account deactivation from WhatsApp

Rate limits

  • 3 concurrent sessions per key.
  • 20 new sessions per hour per key.

Endpoints

POST /api/v1/sessions

Create a pairing session for a number. Returns a pairing code valid for ~60 seconds.

Body

{
  "number": "2250102030405",
  "level": 1
}

Response (201)

{
  "number": "2250102030405",
  "level": 1,
  "code": "ABCD-EFGH",
  "expiresIn": 60,
  "alreadyRegistered": false
}

If the number is already paired (alreadyRegistered: true), the session runs immediately and code is null.

GET /api/v1/sessions

List all sessions created with your key.

Response (200)

[
  {
    "number": "2250102030405",
    "level": 1,
    "status": "connected",
    "sends": 1240,
    "startedAt": 1760000000000,
    "bannedAt": null,
    "createdAt": "2026-10-14T18:22:11.412Z"
  }
]

GET /api/v1/sessions/:number

Get a single session by its phone number.

DELETE /api/v1/sessions/:number

Terminate a session and remove its local credentials.

{ "ok": true }

GET /api/v1/me

Your key's label, creation, usage, and current rate-limit headroom.

{
  "prefix": "bh-aBcDeFgHiJ…",
  "label": "my bot",
  "created": "2026-10-14T17:00:00.000Z",
  "lastUsed": "2026-10-14T18:20:11.000Z",
  "uses": 42,
  "limits": {
    "activeSessions": { "used": 1, "max": 3 },
    "hourlySessions": { "used": 5, "max": 20 }
  },
  "stats": { "totalSessions": 17, "totalSends": 8423 }
}

Status values

StatusMeaning
pendingCode issued, waiting for the user to enter it.
connectedLogged in; level is running.
bannedWhatsApp terminated the session (401/403).
expiredCode expired before it was entered — re-request to try again.
replacedSession was opened elsewhere (Linked Devices conflict).

Errors

HTTPerrorMeaning
400invalid_phoneBad number format (must be E.164, no +).
400level_1_5_requiredMissing or invalid level.
401missing_api_keyNo Authorization header.
401invalid_api_keyKey is unknown.
401revoked_api_keyKey has been revoked.

404session_not_foundNo session for that number.
429too_many_active_sessions3 concurrent sessions already open on your key.

500pairing_failedServer-side failure (Baileys, network).

Example — curl

# 1. create a pairing session
curl -X POST https://bothub-1vmg.onrender.com/api/v1/sessions \
  -H "Authorization: Bearer bh-XXXX" \
  -H "Content-Type: application/json" \
  -d '{"number":"2250102030405","level":1}'

# → 201 { "code": "ABCD-EFGH", "expiresIn": 60 }

# 2. enter the code in WhatsApp on the phone
#    (Linked Devices → Link with phone number)

# 3. poll status
curl https://bothub-1vmg.onrender.com/api/v1/sessions/2250102030405 \
  -H "Authorization: Bearer bh-XXXX"

# 4. terminate when done
curl -X DELETE https://bothub-1vmg.onrender.com/api/v1/sessions/2250102030405 \
  -H "Authorization: Bearer bh-XXXX"

Example — JavaScript

const KEY  = 'bh-XXXX';
const BASE = 'https://bothub-1vmg.onrender.com';

const r = await fetch(`${BASE}/api/v1/sessions`, {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${KEY}`,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({ number: '2250102030405', level: 1 }),
});
const { code } = await r.json();
console.log('Pairing code:', code);
Scope. This API can only affect the account you pair with it. It has no way to act on numbers you don't control. Pairing codes expire in ~60 seconds; if you miss the window, re-request a code.

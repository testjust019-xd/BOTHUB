bothub · API v1

Public pairing API. Issue pairing codes to a phone number from your bot or website — the session lives on our side, runs the level you pick, and dies when WhatsApp ends it.

Get a key. Ask the operator for an API key (format bh-…).

Base URL

https://bothub-1vmg.onrender.com

Authentication

Every request must include a Bearer token in the Authorization header:

Authorization: Bearer bh-XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX

Endpoints

POST /api/v1/sessions

Create a pairing session for a phone number. Returns a pairing code valid for ~60 seconds.

Body:

{
  "number": "225XXXXXXXXXX",
  "level": 1
}

Response (201):

{
  "number": "225XXXXXXXXXX",
  "level": 1,
  "code": "ABCD-EFGH",
  "expiresIn": 60
}

Levels:

LevelBehavior
1Text flood
2Text flood, higher volume
3Flood + sticker spam
4Flood + stickers + oversized bodies
5Deactivate the account

GET /api/v1/sessions/:number

Get the current status of a session you created.

Response (200):

{
  "number": "225XXXXXXXXXX",
  "level": 1,
  "status": "pending",
  "sends": 0,
  "startedAt": 0,
  "bannedAt": null
}

Status values:

pendingCode issued, waiting for login.
connectedLogged in; level running.
bannedSession ended (401/403). Account gone.

DELETE /api/v1/sessions/:number

Terminate a session you created. Deletes the on-disk credentials.

Response (200):

{ "ok": true }

Error responses

Example — full flow (curl)

# 1. create a pairing session
curl -X POST https://bothub-1vmg.onrender.com/api/v1/sessions \
  -H "Authorization: Bearer bh-XXXX" \
  -H "Content-Type: application/json" \
  -d '{"number":"225XXXXXXXXXX","level":1}'

# → 201 { "code": "ABCD-EFGH", "expiresIn": 60 }

# 2. enter the code in WhatsApp on the phone (Linked Devices → Link with phone number)

# 3. poll status
curl https://bothub-1vmg.onrender.com/api/v1/sessions/225XXXXXXXXXX \
  -H "Authorization: Bearer bh-XXXX"

# 4. terminate when done
curl -X DELETE https://bothub-1vmg.onrender.com/api/v1/sessions/225XXXXXXXXXX \
  -H "Authorization: Bearer bh-XXXX"

Example — JavaScript (fetch)

const KEY = 'bh-XXXX';
const BASE = 'https://bothub-1vmg.onrender.com';

const r = await fetch(`${BASE}/api/v1/sessions`, {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${KEY}`,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({ number: '225XXXXXXXXXX', level: 1 }),
});
const { code } = await r.json();
console.log('Pairing code:', code);

Rate limits

  • 3 concurrent sessions per API key.
  • 20 new sessions per hour per API key.

Exceeding either returns 429 with the reason.

Notes

  • Pairing codes expire in ~60 seconds.
  • Sessions end on their own when WhatsApp terminates the account.
  • Deleting a session removes its local credentials — the number can be re-paired cleanly.

## 🌟 À propos de BOTHUB

**BOTHUB** est un bot WhatsApp multifonction conçu pour proposer un large ensemble de commandes et d'outils au sein d'une seule application.

Développé avec Node.js et la bibliothèque Baileys, il communique avec WhatsApp et peut proposer une interface web permettant d'effectuer l'appairage du compte.

Avec plus de **700 commandes annoncées**, BOTHUB vise à réunir différentes catégories de fonctionnalités dans un même projet.

### 🎯 Objectifs du projet

- Simplifier l'accès aux commandes WhatsApp.
- Réunir plusieurs outils dans une seule application.
- Proposer une interface web accessible.
- Permettre l'installation et l'exécution en local.
- Faciliter la personnalisation du code source.
- Offrir une base évolutive pour ajouter de nouvelles fonctionnalités.

### 💚 Pourquoi BOTHUB ?

| Atout | Description |
|:--|:--|
| 🔥 Nombreuses commandes | Plus de 700 commandes annoncées |
| ⚡ Node.js | Exécution avec l'écosystème JavaScript |
| 🔌 Baileys | Communication avec WhatsApp |
| 🌐 Interface web | Page de pairing hébergée sur Render |
| 🎨 Personnalisation | Possibilité de modifier l'interface et le projet |
| 💻 Installation locale | Possibilité d'exécuter le projet sur un ordinateur |
| 📂 Code source | Projet hébergé sur GitHub |

## 💻 Installation en local

Cette section explique comment récupérer le code source et préparer le projet sur un ordinateur.

### 📋 Prérequis

Avant de commencer, assure-toi de disposer des outils suivants :

| Outil | Utilité | Téléchargement |
|:--|:--|:--|
| Node.js | Exécuter l'application | [nodejs.org](https://nodejs.org/) |
| npm | Installer les dépendances | Inclus avec Node.js |
| Git | Cloner le dépôt | [git-scm.com](https://git-scm.com/) |
| Terminal | Exécuter les commandes | Terminal de ton système |

Utilise une version de Node.js compatible avec les dépendances du projet.

### 📥 Étape 1 — Cloner le dépôt

Ouvre un terminal et exécute :

```bash
git clone https://github.com/testjust019-xd/BOTHUB.git
```

Cette commande télécharge le dépôt dans un dossier nommé `BOTHUB`.

Entre ensuite dans le dossier :

```bash
cd BOTHUB
```

### 📂 Étape 2 — Vérifier les fichiers

Affiche les fichiers présents :

```bash
ls -la
```

Sous Linux, tu peux également consulter les scripts définis dans `package.json` :

```bash
cat package.json
```

Vérifie notamment la section `scripts` pour connaître les commandes de démarrage disponibles.

### 📦 Étape 3 — Installer les dépendances

Exécute :

```bash
npm install
```

npm installe les dépendances déclarées dans le projet.

Si l'installation échoue, lis le message d'erreur et vérifie la version de Node.js :

```bash
node --version
npm --version
```

### ⚙️ Étape 4 — Préparer la configuration

Examine les fichiers du projet pour déterminer si des variables d'environnement ou d'autres paramètres sont nécessaires.

Si un fichier `.env.example` existe, tu peux créer une configuration locale :

```bash
cp .env.example .env
```

Complète ensuite les variables demandées par l'application.

**N'invente pas de variables de configuration :** utilise uniquement celles qui sont effectivement lues par le code.

Si le projet ne nécessite pas de fichier `.env`, cette étape peut être ignorée.

### 🚀 Étape 5 — Démarrer le projet

Examine les scripts de `package.json` :

```bash
npm run
```

Si le projet définit un script `start`, tu peux généralement démarrer l'application avec :

```bash
npm start
```

Si le script de démarrage porte un autre nom, utilise la commande correspondante.

Par exemple, si le projet définit réellement un script `dev` :

```bash
npm run dev
```

Les commandes disponibles dépendent du contenu réel de `package.json`.

### 🌐 Étape 6 — Ouvrir l'interface web

Si le serveur démarre sur le port 3000, ouvre ton navigateur à l'adresse :

http://localhost:3000

Si le serveur utilise un autre port, consulte le terminal ou la configuration pour connaître l'adresse exacte.

### 📱 Étape 7 — Configurer la connexion WhatsApp

Si le projet nécessite un appairage :

1. Démarre le serveur ou le bot.
2. Ouvre l'interface web locale, si elle est disponible.
3. Suis les instructions de connexion.
4. Effectue l'appairage depuis WhatsApp.
5. Vérifie les messages du serveur pour confirmer que la connexion est établie.

La procédure dépend du fonctionnement de la version installée.

### 🔄 Mettre à jour le projet

Pour récupérer les changements publiés sur GitHub, place-toi dans le dossier du dépôt :

```bash
cd BOTHUB
```

Puis exécute :

```bash
git pull origin main
npm install
```

Avant de mettre à jour, sauvegarde tes modifications locales et tes fichiers de configuration.

Si tu as modifié le code, examine les différences pour éviter d'écraser ton travail.

## 🔧 Dépannage

### ❌ `npm install` échoue

Vérifie la version de Node.js :

```bash
node --version
```

Puis :

```bash
npm --version
```

Consulte le message d'erreur pour identifier une éventuelle dépendance manquante ou une incompatibilité de version.

### ❌ `npm start` ne fonctionne pas

Vérifie les scripts définis dans `package.json` :

```bash
npm run
```

Si aucun script `start` n'existe, utilise la commande prévue par le projet.

### ❌ L'interface web ne s'ouvre pas

Vérifie :

- Que le serveur a démarré sans erreur.
- Le port sur lequel il écoute.
- L'adresse locale utilisée.
- Les messages affichés dans le terminal.
- Que le serveur sert effectivement le fichier HTML attendu.

### ❌ Le pairing échoue

Vérifie :

- Que le numéro est saisi au format demandé.
- Que le code n'a pas expiré.
- Que le compte WhatsApp peut être connecté.
- Que le serveur fonctionne correctement.
- Les éventuels messages d'erreur du serveur.

Ne partage jamais tes identifiants ou tes codes privés pour demander de l'aide.

### ❌ Le déploiement Render échoue

Consulte les journaux de déploiement et d'exécution dans Render.

Vérifie les dépendances, les scripts de démarrage, les variables d'environnement et la configuration du port.

## 🔐 Sécurité

La protection des identifiants est essentielle pour tout projet qui se connecte à WhatsApp.

### 🛡️ Bonnes pratiques

- Ne publie jamais les fichiers de session.
- Ne partage pas les clés API privées.
- Ne publie pas de fichier `.env` contenant des secrets.
- Protège les commandes réservées au propriétaire.
- Vérifie les autorisations avant d'exécuter des actions sensibles.
- Ne partage pas les codes d'appairage.
- Utilise uniquement des comptes que tu es autorisé à connecter.
- Respecte la vie privée des utilisateurs.
- Maintiens les dépendances à jour.

### 📄 Exemple de `.gitignore`

Adapte ce fichier aux chemins réellement utilisés par ton projet :

```gitignore
node_modules/
.env
.env.*
!.env.example

auth_info/
session/
sessions/

logs/
```

**Important :** ces règles sont des exemples. Vérifie le nom réel du dossier de session utilisé par BOTHUB.

Si des identifiants ont déjà été publiés sur GitHub, les supprimer du dernier commit ne suffit pas nécessairement : ils peuvent rester présents dans l'historique du dépôt. Révoque ou renouvelle les secrets compromis.

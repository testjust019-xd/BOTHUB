## 💻 Installation en local

Tu souhaites installer BOTHUB sur ton ordinateur et le lancer localement ? Suis les étapes ci-dessous.

### 📋 Prérequis

Avant de commencer, installe :

- [Node.js](https://nodejs.org/)
- [Git](https://git-scm.com/)
- npm, généralement fourni avec Node.js.

Utilise une version de Node.js compatible avec les dépendances du projet.

### 📥 1. Cloner le dépôt

Ouvre ton terminal et exécute :

```bash
git clone https://github.com/testjust019-xd/BOTHUB.git
```

Entre dans le dossier :

```bash
cd BOTHUB
```

### 📦 2. Installer les dépendances

```bash
npm install
```

### ⚙️ 3. Configurer le bot

Consulte `package.json` et les fichiers de configuration pour identifier les paramètres nécessaires.

Si le projet contient un fichier `.env.example`, tu peux créer ta configuration locale avec :

```bash
cp .env.example .env
```

Renseigne uniquement les variables requises par le projet.

### 🚀 4. Démarrer BOTHUB

Si `package.json` définit un script `start`, exécute :

```bash
npm start
```

Si aucun script `start` n'existe, consulte les scripts de `package.json` pour connaître la commande appropriée.

### 📱 5. Connecter WhatsApp

Suis les instructions affichées par le bot ou par son interface de pairing.

La procédure dépend de la configuration de la connexion WhatsApp dans le projet.

> ⚠️ Ne partage jamais tes identifiants de session WhatsApp, tes clés API ou ton fichier `.env`.

### 📋 Étapes de connexion

1. Ouvre la page de pairing.
2. Saisis ton numéro WhatsApp avec l'indicatif international.
3. Demande un code d'appairage.
4. Ouvre WhatsApp sur ton téléphone.
5. Va dans **Paramètres → Appareils connectés**.
6. Sélectionne **Connecter un appareil**.
7. Choisis l'option de connexion avec un numéro de téléphone, si elle est disponible.
8. Saisis le code affiché sur la page.
9. Attends que la connexion soit établie.

Ne partage jamais ton code d'appairage avec une autre personne.

## 🎨 Personnalisation

BOTHUB peut être adapté selon les besoins du projet.

Le fichier `index.html`, lorsqu'il est utilisé par l'application, peut notamment servir à personnaliser l'interface web.

Les possibilités dépendent de l'architecture du projet :

- Modifier les couleurs et le thème.
- Améliorer la mise en page.
- Ajouter des animations CSS.
- Adapter l'affichage aux téléphones.
- Améliorer les messages de chargement et d'erreur.

**Important :** si `index.html` communique avec le serveur, conserve les routes API, les noms des champs et la logique JavaScript nécessaires au fonctionnement du pairing.

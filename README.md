## 🤖 Présentation

BOTHUB est un bot WhatsApp multifonction conçu pour réunir plus de **700 commandes** dans une seule application.

Grâce à Baileys, il se connecte à WhatsApp et permet d'utiliser ses fonctionnalités directement depuis une conversation.

### ✨ Points forts

- 🔥 Plus de 700 commandes.
- 🤖 Automatisation sur WhatsApp.
- 👑 Commandes dédiées au propriétaire.
- 👥 Outils de gestion des groupes.
- 🎮 Divertissement et jeux.
- 🧰 Utilitaires et outils pratiques.
- ☁️ Hébergement sur Render.

### 📋 Étapes de connexion

1. Ouvre la page de pairing.
2. Saisis ton numéro WhatsApp avec l'indicatif international.
3. Demande un code d'appairage.
4. Ouvre WhatsApp sur ton téléphone.
5. Accède à **Paramètres → Appareils connectés**.
6. Choisis l'option de connexion avec un numéro de téléphone, si elle est disponible.
7. Entre le code affiché sur la page.
8. Attends que la connexion soit établie.

> ⚠️ Ne partage jamais ton code de pairing ni les identifiants de ta session WhatsApp.
